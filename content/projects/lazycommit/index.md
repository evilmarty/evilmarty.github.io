lazycommit is a Go command-line tool that generates a commit message from your staged Git diff using a pluggable LLM provider, then opens it in your editor for review before committing. It supports GitHub Copilot, OpenAI-compatible APIs including Ollama and LM Studio, and the local apfel model on macOS.
